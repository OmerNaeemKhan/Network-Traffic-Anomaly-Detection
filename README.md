# Network Traffic Anomaly Detection

## Project Overview

This project is an AI-powered cybersecurity solution for detecting anomalies in network traffic.

The system uses machine learning, Python, SQL, and an interactive Streamlit dashboard to analyze network traffic data and identify potentially suspicious or anomalous activity.

The project demonstrates the use of:

- Python for data processing and machine learning
- Isolation Forest for AI-based anomaly detection
- SQL database integration for querying network data
- Streamlit for an interactive dashboard
- Plotly and Altair for data visualization
- Pandas and NumPy for data analysis

---

# Features

## 1. AI-Powered Anomaly Detection

The project uses the Isolation Forest machine learning algorithm to identify unusual patterns in network traffic.

The model analyzes multiple network traffic features and classifies records as:

- Normal Traffic
- Anomalous Traffic

---

## 2. Interactive Cybersecurity Dashboard

The Streamlit dashboard provides multiple sections:

### Overview
Displays a high-level summary of the network traffic analysis, including:

- Total records processed
- Number of features analyzed
- Total anomalies detected
- Anomaly detection rate

### Anomaly Analysis
Provides visual analysis of detected anomalies and network traffic patterns.

### Prediction Results
Displays the results generated by the anomaly detection model.

### Model Performance
Provides information about the Isolation Forest model and the distribution of normal versus anomalous traffic.

### About Project
Explains the project architecture, technologies, and objectives.

The dashboard also supports theme selection.

Installation
Step 1: Download or Clone the Project

Download the project files and extract them to a folder.

Open the project folder using Visual Studio Code.

Step 2: Create a Virtual Environment

Open a terminal in the project directory and run:
python -m venv .venv
Activate the virtual environment.

Windows PowerShell

Step 3: Install Required Packages

Run:
pip install -r requirements.txt

Machine Learning Model

The project uses an Isolation Forest algorithm for anomaly detection.

Isolation Forest is an unsupervised machine learning algorithm designed to identify unusual or abnormal observations within a dataset.

The model works by isolating observations that differ significantly from normal traffic patterns.

The trained model is stored as:

normal_traffic_isolation_forest.pkl

The feature preprocessing scaler is stored as:
feature_scaler.pkl
SQL Integration

## Dataset

This project uses the public UNSW-NB15 network traffic dataset (training and testing sets).
The raw CSV files and the large generated outputs are not stored in this repository because of their size.

To run the project:

1. Download `UNSW_NB15_training-set.csv` and `UNSW_NB15_testing-set.csv` from the UNSW-NB15 dataset page (UNSW Canberra).
2. Place both files in `Data/Raw/`.
3. Run `Src/predict.py` to generate the prediction results, then `setup_database.py` to build the SQLite database.

The trained Isolation Forest model and feature scaler are included in `Outputs/`.
